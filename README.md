# Smart Warranty Checker

Smart Warranty Checker is a simple Python application that helps users manage product warranty information in one place.

It allows users to add products, view saved products, check warranty status, search for products, record service or repair details, and delete product records.

## Features

- Add and store product details
- Automatically calculate warranty expiry dates
- Check warranty status
- Identify warranties that are expiring soon
- Search for products
- Add service and repair details
- Delete product records
- Store data using JSON
- Simple menu-driven interface

## Technologies Used

- Python
- JSON
- datetime module
